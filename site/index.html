Multiplexer backends

One client. Four engines. No second brain.

Backends keep sovereignty over sessions, panes, scrollback and agent lifecycle. Shardlane projects whichever engine you point it at — switch without losing state, mix local and remote in one sidebar.

Default runtime

Herdr

The agent-first multiplexer and Shardlane's primary authority. Owns workspaces, tabs, panes, scrollback and full agent lifecycle — with lossless context transfer between providers.

  • Agent semantics, never PTY guesswork
  • Context Transfer & Live Handoff
  • Persisted across restarts

Industry standard

tmux

The classic terminal multiplexer, projected into a native shell. Shardlane drives a real tmux attach child on a PTY — your existing servers and .tmux.conf keep working untouched.

  • Zero-config adoption of live sessions
  • Split / zoom / swap via native menu
  • Works over SSH out of the box

UU Remote

  • Same pane ops as every backend
  • Capability-gated, never brittle

Native multi-workspace

A workspace per project. A project per obsession.

A workspace is a live backend instance — not a folder in some registry. Every window binds to one; the sidebar lists them all across every connected engine. Quit the app, kill the machine, come back tomorrow: layout, cwd and scrollback are exactly where the backend kept them.

  • Live enumeration. Instances come from the backends themselves — no stale client-side registry to rot.
  • Display names stay yours. Rename anything; the runtime keeps its real identity.
  • One TUI child per instance. Desktop and mobile viewers share it; idle children get reaped.

Consumers never branch on backend identity — differences flow through capability flags, so a backend without agents simply hides agent surfaces instead of faking them. Read the API contract.

Agents, first-class

Launch, watch, prompt, resume. Semantic operations over Herdr's protocol — never keystrokes into a PTY. Context Transfer moves a task between providers with its memory intact.

Install

  1. 01
    Download

    Shardlane-macos-aarch64.zip from the latest release.

  2. 02
    Verify

    shasum -a 256 -c Shardlane-macos-aarch64.zip.sha256

  3. 03
    Install

    Unzip, drag Shardlane.app to Applications.

  4. 04
    First launch

    Right-click the app, choose Open once. Ad-hoc signed, not notarized.
