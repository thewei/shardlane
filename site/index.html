Native multi-workspace

A workspace per project. A project per obsession.

A workspace is a live backend instance — not a folder in some registry. Every window binds to one; the sidebar lists them all across every connected engine. Quit the app, kill the machine, come back tomorrow: layout, cwd and scrollback are exactly where the backend kept them.

  • Live enumeration. Instances come from the backends themselves — no stale client-side registry to rot.
  • Display names stay yours. Rename anything; the runtime keeps its real identity.
  • One TUI child per instance. Desktop and mobile viewers share it; idle children get reaped.

Agents, first-class

Launch, watch, prompt, resume. Semantic operations over Herdr's protocol — never keystrokes into a PTY. Context Transfer moves a task between providers with its memory intact.
