macOS · Apple Silicon

A native macOS workspace for coding agents.

Shardlane projects the Herdr runtime — workspaces, tabs, panes, terminals, and agent sessions — into a fast native interface built on GPUI and libghostty. Herdr stays the backend authority; Shardlane is the client.

Install

  1. Download the ZIP and verify the checksum: shasum -a 256 -c Shardlane-macos-aarch64.zip.sha256
  2. Unzip and drag Shardlane.app into Applications.
  3. First launch: right-click the app and choose Open once to approve it in Gatekeeper.

Shardlane needs the Herdr runtime. If it is missing, the app offers to install it with wax install herdr on first run.

What it does

Multiplexed terminals

Workspaces, tabs, and panes owned by Herdr, rendered through vendored libghostty-vt — sessions survive restarts.

Coding agents

Launch agents, follow live sessions, browse external conversation history, and resume work through Herdr — not by typing into a PTY.

Native speed

GPU-rendered with GPUI, native menus and shortcuts, no Electron, no telemetry, no cloud accounts.

Mobile companion

Optionally embeds a Mobile Web bundle served by the Host Remote API — one runtime, every screen.

Architecture

Ownership is intentionally narrow: Herdr is the runtime authority, libghostty-vt owns terminal semantics, gpui-component / GPUI provide the native UI layer, and the Shardlane shell handles presentation, navigation, and local settings. Runtime capabilities are added at the Herdr boundary, never as a second local runtime. Read the product architecture.
